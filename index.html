Como funciona

Medição de verdade

Loudness integrado conforme ITU-R BS.1770-4: filtro K-weighting, blocos de 400 ms e gating absoluto (−70 LUFS) e relativo (−10 LU). LRA conforme EBU Tech 3342.

Limiter true peak

Detecção de picos inter-amostra com oversampling 4x e lookahead: o ganho já está reduzido quando o pico chega, sem clipping.

Privado por design

Todo o processamento roda no seu navegador. O áudio nunca é enviado a nenhum servidor.

Perguntas frequentes

Qual loudness devo usar para o Spotify?

O Spotify normaliza a reprodução em −14 LUFS e recomenda true peak de no máximo −1 dBTP (−2 dBTP se a faixa for mais alta que −14 LUFS).

Qual a diferença entre sample peak e true peak?

O sample peak é o maior valor entre as amostras. O true peak estima o pico real do sinal analógico reconstruído entre as amostras, que pode ser maior e causar distorção na conversão ou em codecs.

Meu arquivo é enviado para algum lugar?

Não. A decodificação, a análise e a exportação acontecem no seu dispositivo.

Por que exportar em 24-bit?

Mantém resolução máxima para entrega ou masterização. Use 16-bit (com dither) para CD ou quando a plataforma exigir.
